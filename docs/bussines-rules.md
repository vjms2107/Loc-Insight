Regras de Negócio

RN01:
Equipamentos em manutenção não aparecem no catálogo público.

RN02:
Equipamentos alugados não podem receber nova reserva.

RN03:
Checklist de devolução é obrigatório antes da mudança de status para “Disponível”.

RN04:
Pontos só são gerados para devoluções sem avarias.

RN05:
Manual PDF deve ser obrigatório no cadastro.
